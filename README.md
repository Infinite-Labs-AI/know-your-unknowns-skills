# Know Your Unknowns Skills

Skill pack for Codex and Claude that turns hidden assumptions into reviewable artifacts.

## Install

From GitHub:

```bash
npx github:Infinite-Labs-AI/know-your-unknowns-skills
```

After npm publication:

```bash
npx know-your-unknowns-skills
```

By default the installer copies the skills into both:

- `~/.codex/skills`
- `~/.claude/skills`

Use `--codex-only`, `--claude-only`, `--dry-run`, or `--force` as needed.
