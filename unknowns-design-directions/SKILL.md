# Unknowns Design Directions

## Workflow

Create divergent options from the same content and constraints.

Return:

- 3-4 genuinely different directions, not minor theme variations.
- For each: intent, strengths, tradeoffs, what to steal, what to skip.
- A reaction capture loop: choose direction, steal details, reject details.
- A generated reply or next prompt that encodes the user's choices.
- Stop condition: the user has selected a direction or produced a combined direction brief.

## Rules

Make options distinct in information density, layout logic, interaction model, and visual tone. Do not let all directions share the same skeleton.

Use HTML when side-by-side visual review or selectable chips materially improves the decision.
